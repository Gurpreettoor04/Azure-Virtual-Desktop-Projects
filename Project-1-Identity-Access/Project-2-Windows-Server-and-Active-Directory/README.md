# Windows Server and Active Directory Domain Services

## Objective
Deploy a Windows Server 2025 virtual machine and implement
Active Directory Domain Services by creating a domain and
configuring a domain controller.

## Technologies Used
- Windows Server 2025
- Active Directory Domain Services (AD DS)
- DNS

## Implementation
- Deployed Windows Server 2025 virtual machine
- Installed Active Directory Domain Services role
- Created a forest root domain
- Promoted server to domain controller
- Configured DNS services
- Created Organizational Units (OUs)
- Created and managed domain users

## Validation
- Verified domain controller functionality
- Confirmed DNS and domain services
- Validated user authentication within the domain

## Learnings
- Active Directory domain architecture
- Domain controller role and responsibilities
- Organizational unit and user management
